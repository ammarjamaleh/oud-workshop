# Ibrahim Oud Workshop

A bilingual (English / Arabic) concept website for an oud-making workshop. It is a personal front-end portfolio project: it is **not** the official website of any workshop, there is no client and no backend, and all products, prices, makers and reviews are sample content.

## Features

- **Two languages with full RTL support.** One click switches between English (LTR) and Arabic (RTL). The page direction, fonts and all dynamic sections are re-rendered.
- **Instrument collection.** Cards generated from a data file, with a detail modal for each oud (woods, price, delivery time).
- **Compare tool.** Select two or more ouds and compare them side by side.
- **Listening section.** Audio player interface with a "coming soon" state (no audio samples are included).
- **Content sections.** Makers, wood guide, reviews (sample), sold gallery and a journal.
- **Custom order form.** Includes an estimated delivery time that depends on the selected grade. The form is front-end only and shows a confirmation message without sending data.
- **Instrument illustration.** The oud in the hero and on the cards is an inline SVG generated by JavaScript (`oudSVG()` in `js/app.js`).
- **Responsive layout** with a mobile navigation drawer and scroll animations.

## Tech stack

HTML5, CSS3 (custom properties, flexbox, grid) and vanilla JavaScript. No frameworks or build step. Fonts: Cormorant Garamond, DM Sans, Lateef and Tajawal from Google Fonts.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Project structure

| Path | Purpose |
| --- | --- |
| `index.html` | Page structure |
| `css/style.css` | Styles, themes and responsive rules |
| `js/data.js` | Sample content: ouds, makers, woods, reviews, journal posts |
| `js/app.js` | Rendering, language switching, modals, compare tool, audio player, form handling |

## Limitations

- Front end only: forms do not send anything.
- Contact links (WhatsApp, Telegram, email) are placeholders and point to the order form or to `example.com`.
- Sample content only: prices, people, reviews and specifications are illustrative.
- Google Fonts are loaded from Google's servers. For a production site in the EU, host the fonts yourself.

## About the content
The workshop name and the makers' names are used with the permission of the family. Everything else (products, prices, specifications, reviews) is invented for this concept project. This is not the official website of the workshop.
